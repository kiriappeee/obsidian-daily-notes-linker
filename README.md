# Obsidian daily note linker

The daily notes in Obsidian are nice but the linking of previous to next notes is something that is done within the Obsidian plugin itself. This means that the logic is not stored in the markdown file itself which makes the repo of files the tiniest bit less portable. 

My own daily notes have a previous/next link at the top of each file. But everyday, I have to relink them and that is tedious and sometimes results in linking lots of notes at once in order to catch up. This plugin will simply grant a shortcut to link the daily notes once they've been created. Over time it may become more advanced and might manage daily notes the way I like to do it completely (including managing my journal files which I keep separate from the daily note) but for now, it's just the functionality of linking the new daily note and the previous one after creating a new daily note
